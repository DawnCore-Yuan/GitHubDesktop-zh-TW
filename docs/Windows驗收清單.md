# Windows 實機驗收清單

本清單供 Windows 測試者在 **GitHub Desktop 3.6.10 x64** 上執行。
每一項請填寫實際結果（通過／失敗／不適用）並附截圖檔名。

## 0. 前置

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| 0.1 | 確認 GitHub Desktop 版本為 3.6.10 | 設定 → 關於 顯示 3.6.10 | |
| 0.2 | 完全結束 GitHub Desktop | 工作管理員無 GitHubDesktop 程序 | |
| 0.3 | 記錄安裝路徑（預設 `%LOCALAPPDATA%\GitHubDesktop`） | | |

## 1. 安裝

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| 1.1 | 雙擊 `install.cmd` | 顯示 `Completed.` | |
| 1.2 | 檢查 `.zh-original-3.6.10` 備份資料夾 | 內含 3 個原檔 | |
| 1.3 | 重新啟動 GitHub Desktop | 介面為繁體中文 | |
| 1.4 | 重複執行 `install.cmd` | 顯示 `Already in the requested state` | |

## 2. 不相容攔截

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| 2.1 | 手動修改 `renderer.js` 任一位元組後執行 `install.cmd` | `Unsupported or modified file`，且不改動任何檔案 | |
| 2.2 | 還原該檔案後再執行 | 恢復正常 | |

## 3. 還原

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| 3.1 | 雙擊 `restore.cmd` | 顯示 `Completed.` | |
| 3.2 | 啟動 GitHub Desktop | 介面恢復英文 | |
| 3.3 | 再次安裝 | 可正常安裝 | |

## 4. 核心 Git 操作（需測試儲存庫）

| # | 操作 | 檢查重點 | 結果 |
|---|---|---|---|
| 4.1 | 新增本機儲存庫 | 選單用語為「新增」非「添加」 | |
| 4.2 | 從網路複製儲存庫 | 「複製」非「克隆」 | |
| 4.3 | 建立提交 | 按鈕為「提交」，訊息欄標籤正確 | |
| 4.4 | 切換分支 | 「分支」用語一致 | |
| 4.5 | 擷取（Fetch） | 不顯示為「獲取」 | |
| 4.6 | 拉取（Pull） | | |
| 4.7 | 推送（Push） | | |
| 4.8 | 合併（Merge） | 衝突提示用語準確 | |
| 4.9 | 衝突處理 | 「衝突」與解決流程文字可讀 | |
| 4.10 | 貯藏變更（Stash） | 全流程顯示「貯藏」，**不得**出現「暫存」 | |
| 4.11 | 捨棄變更（Discard） | 確認對話框語意準確、後果清楚 | |
| 4.12 | 刪除分支 | 為「刪除」非「捨棄」 | |
| 4.13 | 強制推送 | 警告文字完整、無截斷 | |
